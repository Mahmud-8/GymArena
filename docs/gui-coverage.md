# Expected GUI

Design file: https://www.figma.com/design/BLI0uf9XDv3LMcz7EUFYSU

The editable Figma screens cover kiosk onboarding, optional face enrollment, code fallback, supervised assessment, trainer-approved challenges, solo and local 1v1 attempts, interruption recovery, result status, progress, memberships and messaging.

| Requirements | Main views |
| --- | --- |
| FR-01, FR-02 | Camera readiness, solo live, 1v1 live, tracking pause and recovery |
| FR-03, FR-04 | Membership list, member subscription details and renewal |
| FR-05, FR-06 | Session setup, camera readiness, live sessions, recovery, valid and incomplete results |
| FR-07, FR-08 | Reminder settings, message log and follow-up composer |
| FR-09, FR-10 | Registration, scale confirmation, member profile and weight history |
| FR-11, FR-12 | Face consent, returning identity confirmation, member-code fallback and face settings |
| FR-13, FR-14 | Trainer assessment, approved challenge rules, member home and session setup |
| FR-15, FR-16 | Results, member progress, comparable leaderboard and staff overview |

Screen values are illustrative prototype data. Point amounts, thresholds, level boundaries and winner rules must be approved before a ranked implementation uses them.
